# 专注提醒题库接入

题库维护的是当前账户的**自定义题**。APP 始终保留 10 道内置极限题，自定义题同步到设备以后与它们一起出题。切换账户会清理本地缓存，临时断网也可以答题。

在 APP「设置 → 原子岛与提醒 → 验证题库」复制接入 Prompt。它包含生产 URL 和独立的 Bearer 密钥；密钥仅能维护这个账户的题库。点击「更换维护密钥」后旧密钥立即失效。

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `GET` | `/api/reminder-questions/bank` | 返回 `revision` 和 `questions`；尚无自定义题时为 `0` 和 `[]` |
| `PUT` | 同上 | 用下面的 JSON 替换自定义题库；返回新版本和题目 |

使用 `Authorization: Bearer <题库维护密钥>`。写入请求加 `Content-Type: application/json`。`409 question_bank_changed` 时重新读取后再合并，避免覆盖他人的更改。保存后可在 APP 点「同步题库」，或由下次打开提醒页时的后台读取同步。

```json
{
  "expected_revision": 0,
  "questions": [{
    "body": "当 x 趋近于 0 时，求极限。\n$$\n\\frac{1-\\cos x}{x^2}\n$$",
    "options": ["0", "1/2", "1", "−1/2"],
    "answer_index": 1
  }]
}
```

`answer_index` 从零开始。每题 3–5 个不同选项，题干最多 560 字、单选项最多 80 字，自定义题最多 48 道。传空数组清除自定义题。

题干支持 `$…$` 行内公式、由独占行 `$$` 包围的公式、三反引号代码块。公式使用常用的 TeX 子集，支持块级 `\frac{…}{…}`、`\sqrt{…}`、常见函数符号和简短上下标；建议用短式，避免矩阵、宏和复杂嵌套。代码块只显示文字，不执行。请提交前检查每题只有一个正确选项，优先选用一两项幂级数即可化简的极限。
