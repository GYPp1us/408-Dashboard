# 专注提醒题库接入

每个账户有一套题库，所有题目均可编辑和删除。首次读取时，旧版的 50 道题会加入账户题库，已有题目会保留，题干相同则保留账户原有版本。设备使用最近一次成功同步的题库，切换账户会清理本地缓存。

在 APP「设置 → 原子岛与提醒 → 验证题库」复制接入 Prompt。它包含生产 URL 和独立的 Bearer 密钥；密钥仅能维护这个账户的题库。点击「更换维护密钥」后旧密钥立即失效。

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `GET` | `/api/reminder-questions/bank` | 返回 `revision` 和全部题目 `questions` |
| `PUT` | 同上 | 用下面的 JSON 替换整个题库，返回新版本和题目 |

使用 `Authorization: Bearer <题库维护密钥>`。写入请求加 `Content-Type: application/json`，使用 UTF-8 编码。先读取题库再把想保留的题一并提交。`expected_revision` 填读取时返回的版本，收到 `409 question_bank_changed` 后重新读取并合并。保存后可以在 APP 点「同步题库」，或打开首页、提醒页同步。

```json
{
  "expected_revision": 1,
  "questions": [{
    "body": "当 x 趋近于 0 时，求极限。\n$$\n\\frac{1-\\cos x}{x^2}\n$$",
    "options": ["0", "1/2", "1", "−1/2"],
    "answer_index": 1
  }]
}
```

`answer_index` 从零开始。每题 3–5 个不同选项，题干最多 560 字、单选项最多 80 字，服务端题库最多 512 道。提交 `questions: []` 会清空整个题库。清空后须添加题目并同步，才能继续答题。

题干和选项支持 `$…$` 行内公式、由独占行 `$$` 包围的公式、三反引号代码块。公式使用常用的 TeX 子集，支持块级 `\frac{…}{…}`、`\sqrt{…}`、常见函数符号和简短上下标；建议用短式，避免矩阵、宏和复杂嵌套。代码块只显示文字，不执行。提交前检查每题只有一个正确选项。

边缘卡和全屏页都能直接答题。答错后会展示本题的正确选项全文，下方按「下一题」继续。可以用空行分隔题干和答案段落，长文本纵向滚动，较宽的公式和代码块可单独横向滚动。答题时，横屏仅在题干、选项都较短时把两者并排。题库不限于数学，也可使用编程题或普通文字题。
