# v0.3.0 · 主页指数与长按详情

本版将常用信息和操作集中到主页，并增加统一的长按详情：

- 专注指数进入主页，可长按展开详细指数信息；专注事项、热度时段和时间卡片也可从左侧打开带过渡动画的半屏详情。
- 桌面横向面板支持拖动调整列宽；网页窄屏自动按阅读顺序排列，恢复宽屏后保留列宽；Android 竖屏按阅读顺序排列，横屏保留三列。
- 设置可快速调整快捷专注数量（2–8 项），并提供系统/浅色/深色模式和 clay/sage/ocean 配色，按账号保存。
- 时间卡片表情包保留图片比例且不限制最大宽度，可长按上传自定义 PNG/JPEG/GIF/WebP 或恢复默认图；原始图片按账号保存于 SQLite，数据库备份保留图片。上传上限 10 MiB，取消和无效图片保留原图。
- 设置只调整显示偏好时不再重建整段指数历史；本人和访客的详情接口保持账号隔离，跨账号重复 client token 不再泄露专注会话。
- APP 禁止 WebView 自身缩放；网页端图表接管双指及 Ctrl 加滚轮，保留图表内部缩放。修复双指结束被当成日期点击、重新绘制并重置缩放范围的问题，单指日期回看保持可用。

Android 壳层同步修复页面与计时边界：正常联网优先获取当前页面，离线时恢复已缓存路由；CSS/JS 使用内容指纹，更新后不复用旧资源。访客与匿名页面不将浏览对象的专注状态发送到原生服务；设置、账户和指数页收到原生刷新时仅同步本人状态，不运行主页渲染或覆盖表单。登出、身份失效或账号不匹配使用明确的状态清除，避免误触结束提醒；休息保存按账号隔离。

Android 15/API 35 和 Android 16/API 36 模拟器已验证横竖屏、半屏长按详情与返回、系统选图上传/取消/旋转/导航、通知暂停/继续/结束、暂停 5 分钟及结束 15/30/60 分钟提醒、身份隔离和精确路由恢复。额外验证应用悬浮层和无障碍兜底、连续两轮离线重连、实际设备开机恢复、真实锁屏两分钟心跳、真实双指指数缩放以及跨会话同类提醒替换。ProgressStyle 和推广请求已观察到；测试镜像未获 promoted ongoing 推广，普通通知兜底正常。完整范围和复现步骤见 [模拟器验证记录](../android-emulator-validation.md)。
