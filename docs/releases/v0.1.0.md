# v0.1.0 · OriginOS-first Android preview

首个 Android 预览版，将 408 Study Console 迁移为 WebView + 原生计时伴侣：

- 在 vivo/iQOO 上按官方本地通知协议尝试原子岛，未认证场景自动保留普通通知；
- Android 16 Live Update 与 Android 8+ 持续通知双重兜底；
- 通知中支持暂停、继续、结束，后台每 15 秒维持同源专注心跳；
- 首次启动提供通知、无障碍提醒层、悬浮窗、电池不限制、OriginOS 自启动引导；
- 暂停 5 分钟，以及结束后 15/30/60 分钟触发半透明覆盖提醒；
- 红色“继续摸鱼”必须右滑，点击其他区域返回计时器；
- 网页新增休息状态和全屏暂停/休息覆盖层；休息、空闲、正常专注不触发 Android 超时提醒；
- 竖屏卡片改为单列并精简顶部状态信息；横屏保持原控制台布局。

限制：未获 vivo 场景/包名权限时不能承诺出现原子岛，预期降级为普通持续通知。本版本不包含华为适配。
