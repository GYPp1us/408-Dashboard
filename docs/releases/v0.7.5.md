# v0.7.5 · 原子岛提醒与连续时间轴

Android versionName 0.7.5、versionCode 20，沿用既有签名，可覆盖升级。保留旧版本 Release。

- 修正原子岛优先级：正在专注、暂停、休息和刚结束的统计不再被午间开盘倒计时替代。午间空闲时显示下午开盘倒计时。
- 上午、下午开盘后，空闲状态显示“等待下一段专注”，从对应开盘时刻累计等待时间，复用离开提醒的 15 / 30 / 60 分钟节奏。它低于未完成打卡的限定时间倒计时；实际专注结束后的提醒仍保留自己的计时。每个开盘时段分别保存关闭、稍后提醒及展示记录，不创建虚假专注记录。
- 暂停主动提示采用 **15 秒内冻结通知计时画面** 的方案。每轮首次只发送一次主动展开，15 秒内不发送仅时间变化的 UPDATE；内部计时、统计及同步继续，到期补齐最新时间并仅发送一次收起请求。继续专注、关闭提醒、真正的状态变化仍立即更新，手动收起后同轮不会重新请求展开。
- 对照原因：0.7.3 在后续更新中持续携带主动展开命令，用户反馈重复弹出且持续过久；0.7.4 只在首次携带展开命令，但普通逐秒更新在用户设备上仍会让卡片提前收起。公开接口的 `forceShowCard` 负责直接出卡，`showTime` 描述岛的显示时间，并未提供已验证的独立展开保持接口。因此不再把逐秒更新与 15 秒稳定展开同时作为保证，也不使用岛的生存时长模拟卡片保持时间。实际 OriginOS 行为由用户安装 Release APK 验证。
- “距离午休”和“距离闭馆”合并为从上午开盘到闭馆的连续面板，午休按真实时长占据进度条。未过时间、已过时间、午休及专注记录采用四档色深，已过和专注记录比原样式减淡，随账户主题变化。
- 当前时间细线向上连接跟随标签，显示下一时间边界及逐秒倒计时；靠近两端自动换侧、限制边界。拖到窄面板时细线在完整标签下方终止，避免穿过数字。时间刻度按宽度疏密调整，避开首尾刻度。
- 主时间和全天进度之间增加拖动分隔，复用现有分隔样式；支持方向键微调、Home / 双击恢复默认，按账户及客户端保存宽度。保留既有字体大小、面板高度、14px 进度条及小圆角。共享样式在旧 APK 的内置样式之后加载，保留隐藏的旧计时更新目标，兼容尚未升级的客户端。

验证范围：42 项原生、6 项前端计时算法、17 项页面检查通过。另有 3 条排行榜旧断言在基线版本即与已发布实现不一致，其对应代码本次未修改，单独记录为既有问题。隔离浏览器检查覆盖 320 / 412 / 960 / 1440 四种宽度、六个时间边界、拖动极限与保存、六组主题，未发现页面错误或时间标签越界。签名 Release 构建和 lint 通过（0 错误、62 项警告）。未做全量回归、模拟器或真机测试。

生产只更新共享页面、样式和脚本，指数撮合、历史线、打卡结算与数据库结构不变。保留数据库一致性备份和旧 release 回滚路径；发布包 manifest 记录提交、签名、哈希和部署核验。
