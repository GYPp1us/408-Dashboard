# v0.7.0 · APK 体验重构

本版按 [0.7 改动方案](../v0.7-experience-plan.md)重构 Android 端。APK 内打包手机交互脚本、详情脚本、布局样式及缩放脚本，通过同源资源替换生效。沿用现有生产 API；没有修改或部署生产服务端、数据库和网页资源。

## 已实现

- 原子岛按 doc895 重设计：暂停使用强调信息模板，收起态左侧“暂停中”、右侧已暂停 m:ss 时间，展开态显示提醒轮次及一个“继续专注”胶囊。专注使用进度可视化模板，目标专注调用公共进度动态图标，自由专注使用公共加载动态图标；本段结束以左右对称模板显示开始/结束时刻，中间线上显示累计有效专注；今日结算保留左右统计，两者使用公共完成图标。休息中采用与暂停相同的强调模板和累计计时。每张卡片只有一个胶囊操作，移除三个自定义操作图标及长事项文案。
- 暂停、继续、结束使用同一个原生操作入口。执行时显示处理中，返回服务端实际会话；失败时保留实际状态并提供重试。超时后先回读，区分操作已经完成、其他设备已经改变状态和仍未确认，避免重复提交和错误的成功提示。
- 有效专注、暂停时长、休息时间与下一次提醒分别计算。休息状态、目标、提醒处理和延后时间持久保存。退出应用、锁屏、重新打开后继续使用同一个起点；升级旧版本时迁移已保存的休息起点。
- 暂停每满 5 分钟进入下一轮提醒，离开满 15 / 30 / 60 分钟产生阶段提醒。使用 forceShowCard 主动展开原子岛，每一轮只请求一次，重建服务不重复展开本轮。较晚恢复时合并已错过阶段，只提示当前最新轮次。延后与收起协议保留于 APK 本地，岛上的主操作精简为继续或开始专注。
- 按本次要求，计时统计与原子通知 UPDATE 请求每秒一次；所有已确认的状态切换、提醒轮次、主题/重试及收岛立即透传，不等待一秒或十秒窗口。静态总结只在数据变化时更新，同一活动持续 UPDATE，不因模式切换反复 CREATE。changedRecord 持久递增，覆盖安装承接已有通知的序号。原子岛可用时主动提醒只更新并展开同一条原子通知，不重复发送普通提醒或应用覆盖层；原子岛不可用时保留普通通知兜底，强提醒仍需用户主动开启。
- 通知按钮操作使用独立网络线程，慢后台心跳和回读不再挡住暂停/继续/结束；操作开始后拒绝此前后台请求的迟到响应，包括操作未确认时。接口确认后立即发布通知，失败时仍先回读真实状态。release 的 FocusService 日志记录排队、接口、结果应用和通知提交耗时，便于定位真机剩余延迟；未改生产 API 和既有后台 15 秒同步周期。
- 本段结束展示 30 秒岛上总结，随后收岛并等待离开提醒；今日结算停止离开提醒。使用已有 dashboard 中的实际结束记录和结算状态处理跨设备操作。服务端同步失败时保留本机最后确认状态，下一次成功同步再核对。
- 竖屏首页先展示专注与大计时，时间、午休与闭馆合并为紧凑信息区，今日投入紧随其后；详细统计、图表与附加操作按需展开。向下浏览时保留底部计时与快捷操作。详情采用底部面板，设置在窄屏正常换行；旋转不重建 WebView，保留输入与页面状态。横屏首页继续使用原有布局比例。
- 新衬线 M 标识统一应用、通知、原子岛与应用内品牌；包含自适应图标与单色图标；状态图标由原子岛公共动画呈现，操作统一为胶囊按钮。设置入口融入原有设置页，移除 APK 顶部独立占位；原子岛启用、配对及撤销引导沿用相同字体、配色、圆角卡片与按钮，并继续保留固件适配与其他应用场景保护。

## 构建与验证

### UI 修正与 release 替换

根据首包反馈，竖屏首页整体缩至此前的 60%，包括原有模块、字号、间距和按钮。横屏比例与设置页缩放保持原样。新增卡片和按钮使用 8 / 7 px 小圆角、34 px 按钮基准高度及原有字号比例；普通玻璃表面不透明度为 50%，暂停分栏和休息卡片为 42%，并通过背景模糊展示底下的专注内容。原生引导页使用紧凑尺寸和半透明表面，Android 12+ 系统允许时启用窗口模糊，关闭模糊或旧系统时使用实色背景。

暂停页面已恢复 0.6 版本的简洁分栏：暂停时钟持续增长，点击分栏或按回车继续；没有新增状态卡片和按钮栏。412 px 页面实测首页缩放为 0.6，原有 48 px 控件显示为 28.8 px。暂停、休息、详情、320 px 深色设置与横竖屏切换完成检查，无页面异常和横向溢出。UI 修正重新执行原生测试、lint、release 编译及 12 组页面回归，并以同名 APK、校验文件及产物清单替换现有 v0.7.0 release。

Android `versionName=0.7.0`、`versionCode=13`。使用既有 release 签名，可覆盖安装同签名旧版。首发在 GitHub Release 以预发布包提供，真机验收由设备所有者下载 APK 完成。

- 74 项 JVM 单元测试通过；包括同毫秒连续状态变化立即发布、时钟单独按秒刷新、主题/提醒/重试/结算修正不等待、慢后台请求不阻塞操作、操作后旧回读失效及工作线程关闭。还覆盖模板字段、单胶囊按钮、超过一小时不回绕、时长单位切换、账户时区/夏令时/跨日、暂停轮次、真实结算统计、主题色、主动展开持久化及升级序号迁移。原有测试包括提醒持久化、收起、延后、暂停周期、结束阶段、休息恢复、结束总结生命周期、迟到响应和操作结果判断，以及原有本机 ADB 保护测试。
- release 编译及 lint 通过。lint 没有错误；保留既有 SDK/依赖升级建议、后台电量权限等非阻断提醒。
- 本地隔离数据库与真实页面/API、模拟原生桥完成 12 组页面检查：竖屏顺序与触摸尺寸、目标专注、暂停冻结、延后与重载、失败重试、详情不恢复计时、目标休息与重载、底部操作和图表展开、横竖屏、设置入口与草稿、320 px 深色海蓝布局、真实结算停止提醒与打开报告。无页面异常；412 px 首页与 320 px 设置无横向溢出。
- 页面验证使用桌面 Chromium，未启动 QEMU、Android 模拟器或连接真机。它覆盖 APK 打包页面与桥协议，不能作为 vivo 渲染、原生通知操作、后台保活及真实输入法的验收证据。

## 真机验收

详细顺序见 [0.7 真机验证清单](../android-v0.7-validation.md)。重点核对三种模板、单胶囊按钮、暂停轮次与主动展开、后台与锁屏、结算取消提醒，以及同签名覆盖安装。

休息、提醒收起和延后时间保存在当前 APK 内；生产接口没有这些字段，因此它们不会同步到其他设备。专注开始、暂停、继续、结束与今日结算仍通过既有服务端同步。原子岛授权和展示由 OriginOS 控制，现有本机注册适配范围仍限定于已验证固件；没有扩大到尚未验证的机型或 OriginOS 7。

视觉与刷新要求参考 [vivo 原子通知规范 doc895](https://dev.vivo.com.cn/documentCenter/doc/895)，字段参考 [技术规范 doc896](https://dev.vivo.com.cn/documentCenter/doc/896)，Android 通知降级参考 [Android Live Updates 文档](https://developer.android.com/develop/ui/views/notifications/live-update)。

实时状态已按要求移除客户端十秒节流，每秒请求更新并保持实时统计；系统可能独立频控，是否逐秒呈现仍由真机验证。小胶囊统一总分钟 m:ss，展开时长采用 h小时m分钟或m分钟s秒。显示格式不会改写原始秒数，也不会按目标截断时长。所有状态图标与胶囊跟随当前主题色。桌面页面截图仅验证暂停分栏，原生岛的字距、折叠和动画仍由用户使用 release APK 验收。
