# v0.7.4 · 提醒刷新、午间连线与打卡结算

Android versionName 0.7.4、versionCode 19，沿用既有签名，可覆盖升级。保留 0.7.3 等旧版本 Release。

- 单笔成交背景改为 80ms 短闪，仅实际消费一笔成交时触发；同一报价的重复刷新不续亮。指数数字仍按相对昨收的日内涨跌着色，0.1 秒最多一笔的真实逐点成交和逐秒统计保持原有口径。
- 日内线的水平虚线固定在所选交易日的开盘价，首页、详情和完整行情页保持一致；实时成交不会移动该线，切换历史日期会使用对应日期的开盘价。
- 逐笔引擎在每段交易结束时保存最后成交价的边界采样，休盘不发生撮合或随机抽样。首页、详情和完整行情页使用水平直线连接午间休盘，下午开盘价如有变化仅在开盘处跳变。旧曲线缺少精确休盘点时仍可连接最近采样，午休不计入均价的时间权重。引擎修订号升级为 3 以刷新派生曲线，随机种子、撮合价格和结算价格不改。
- 暂停与离开提醒每轮只请求主动展开一次，首次携带 15 秒展示窗口；随后计时 UPDATE 不再反复写入主动展开命令，15 秒后仅发送一次收起请求。已发送的轮次及展示时间持久保存，手动收起、重复心跳和服务重建不会重新请求本轮展开；下一次真实提醒轮次独立处理。“关闭提醒”仍立即停止本次后续提醒。
- 午间休盘期间显示下午开盘倒计时，按账户配置的上午结束/下午开始时间及账户时区计算。它替代普通专注/休息展示，暂停、到期提醒和刚结束/结算的总结优先。显示状态不改变实际专注计时。
- 有时间条件、尚未完成且当前处于限定窗口内的打卡，可以显示剩余时间倒计时；优先级最低。多个候选取最早截止的事项，同截止取稳定的事项顺序；支持跨午夜。完成、到期或更高优先级状态出现即切换，胶囊按钮可打开既有打卡栏。所有时钟复用小胶囊总分钟:秒和展开时长格式，图标沿用主题色。
- 每日总结新增打卡快照，统计区间为 **(结算时刻 − 24 小时，结算时刻]**。完成度按事项去重，同一事项跨自然日有多条打卡时保存实际次数；结算后睡前打卡可以进入次日总结。报告保存事项名称、完成状态和窗口边界，后续新增打卡、改名、归档或跨午夜不改写已保存的报告。旧报告缺失的快照不补造。

原生客户端从已有登录接口同步最小展示配置，不获取打卡地点或上报 key。后台无展示时释放逐秒唤醒锁，按下一时段边界调度；有倒计时时仍逐秒更新。账户切换、退出登录或认证失效会清除本机计划。未增加固件配置写入或调试权限。

针对性验证：31 项后端、18 项前端、49 项原生检查，以及 4 组隔离浏览器检查通过。前端补充覆盖开盘价虚线、实时更新与历史日期切换。浏览器包含真实短闪、午间水平线、原生展示数据交接和打卡总结横竖屏布局。签名 Release 构建及 lint 通过（0 错误、59 项警告，主要为工具/依赖及 SharedPreferences 写法建议）。未做全量回归、模拟器或真机测试；OriginOS 实际展开时长和手动收起行为由用户安装 Release APK 验证。

服务端改动限于休盘采样、展示配置和结算快照，无新增表或结构迁移。上线前保留一致性数据库备份，生产核验及 APK 哈希、签名信息随 Release manifest 提供。
