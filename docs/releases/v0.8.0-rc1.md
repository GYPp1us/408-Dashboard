# 0.8.0-rc1

本版是统一计时重构的第一阶段，并加入紧急原子岛系统计时适配。`versionCode=22`，沿用既有签名，可覆盖升级 0.7.6。本次发布为预发布版，0.7.6 继续作为最新正式版。

## 页面计时

- 主时间、倒计时、全天时间轴、专注/暂停/休息及累计统计使用共同业务秒拍；用单调时钟推算，减少设备改时、重复注册和接口回包引起的不同步跳变。
- 普通首页同步响应合并到下一秒绘制，真实专注状态变化立即显示。增加请求顺序及操作版本校验，防止旧响应覆盖刚完成的操作。
- 页面隐藏时停止业务计时绘制，恢复时显示当前帧。APK 每帧复用同一原生状态快照，专注时间使用单一写入入口。
- 授时模块和时间轴均内置于 APK，兼容现有生产页面，无需部署服务端。

## 原子岛

- 在已验证的 iQOO 15 `V2505A / PD2505B_A_17.1.9.0.W10` 固件上，使用系统自身的计时文字协议，让 SystemUI 自行走秒，减少应用重新投递通知造成的小卡跳变。
- 小胶囊保留总分钟 `m:ss`；大时间继续使用 `h小时m分钟` 或 `m分钟s秒`。跨十分钟格式边界、进度整数百分比变化及明显校正时才更新计时相关通知，真实状态和主题变化仍即时更新。
- 已适配路径采用系统时钟的显示范围：通知、锁屏、岛，排除桌面原子通知组件。未知固件继续使用原兼容方式。
- 主动提醒保留一次展开、15 秒内不因计时重复投递、一次到期收起的策略。系统文字在期间可自行计时，但 **ROM 实际保持展开 15 秒尚未通过正式包真机验收**；本版不保证系统不会提前收卡。

## 验证与范围

42 项前端定向检查、51 项原生相关测试、签名 Release 构建通过；lint 为 0 错误、62 项警告。网页及 APK 旧生产 HTML 兼容模式各检查横竖两种尺寸，计时与暂停正常，无页面脚本异常。已核对版本、签名和打包资源。

没有做全量回归或模拟器测试。旧滑动器测试有两个复用用例在 0.7.6 基线同样失败，本版未处理。最终原子岛表现由用户安装 Release APK 验收，重点观察纯走秒、手动收起、主动提醒、跨十分钟/小时边界及倒计时归零。

生产服务端、数据库和指数计算没有部署变更。500ms 数据同步、原生 15 秒对账、WakeLock 以及行情逐笔通道保持既有策略；哈希增量同步与更深入的后台省电重构留待后续，因此未声称本版已完成整个架构或量化省电。

设计依据与限制见[授时审计](../frontend-timing-audit-v0.7.6.md)和[系统计时实测记录](../atomic-island-system-timer-probe-20261020.md)。
