# 0.9.0 · 每日计划与完成同步

新增每日计划、专注归类和完成记录。Agent 可使用独立、长期有效且可轮换的鉴权 key 上报计划、读取今日待办或更正完成状态；APP 提供上报链接和完整接入 Prompt 复制。

每段专注结束后进入“本段结算与休息”页，展示有效专注、暂停和起止时间，休息时间持续走秒。可以将本段归入任务、标记是否完成，或保存后继续下一段。同一任务支持多段专注，重复保存不会重复计时；其他端修改过任务时先重新读取，避免覆盖新状态。横屏采用两栏布局，旋转后保留当前选择。

每日结算冻结计划完成快照，并在配置 HTTPS 接收地址后自动推送，支持可选 Bearer 鉴权。失败保留队列并重试，重复投递沿用同一事件 ID；取消可能已送达的结算时推送撤销事件。原子岛展示同步中、成功或待处理状态，保留专注、暂停及休息的优先级。尚未配置地址时不会伪报同步成功。

APP 竖屏主页放大至原比例的 1.15 倍并略增侧边留白，重复时钟移至顶部；系统状态栏背景随明暗主题变化。每日结算改为全屏复合布局，保留计划、打卡和原有统计；已有横屏主页和每日结算布局保留。计划与打卡完成标记统一为随主题着色、固定画布居中的 SVG 图标。

修复切换上级项目后子级纸带无法拖到部分选项的问题，兼容缩放坐标、程序居中、触摸滚动及键盘选择。

每日计划、备注、完成历史和接入设置保持账户私有；访客继续读取既有公开专注统计。协议详见 [Daily Plan v1](../daily-plan-agent-protocol.md)。

本版包含 APK 与服务端更新。数据库升级仅增加每日计划相关六张表，升级前对生产数据库副本演练，备份后再切换；不调整指数算法或改写既有专注、打卡、成绩和历史线。

验证包含 106 项后端、59 项前端和 25 项原子岛相关定向用例，以及 Android 模拟器页面、旋转、返回键和休息计时检查。未进行全量回归；vivo 原子岛的实际显示由正式 APK 真机验收。

Android 包名 `com.mutsumi.focus`，`versionCode=24`，沿用既有正式签名，生产地址 `https://platform.arcol.site/`。安装包不含调试服务地址或测试 CA。
