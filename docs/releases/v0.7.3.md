# v0.7.3 · 紧凑入口、滑动打卡与日内线修复

Android versionName 0.7.3、versionCode 18，沿用原 release 签名。当前 Release 已替换为曲线显示修订包，可覆盖安装此前 versionCode 17 的 0.7.3。源码、生产服务和 APK 一并更新，保留旧版本 Release。

2026-10-18 曲线显示修订：分钟采样同时包含成交价 `price` 和价值锚点 `value`。首页、详情页与完整行情页此前优先读取了 `value`，导致实际成交波动被近似直线替代，末端连接实时成交价时出现突折，时间加权均价也受影响。现统一优先使用 `price` 绘图、定位事件标记和统计均价，兼容既有仅提供 `value` 的数据。这项修正不改撮合算法、服务端采样、历史价格或数据库结构。

本次修订的 12 项前端针对性检查通过；使用 10 月 18 日 10:57:21 的生产库只读副本重建，148 个分钟点全部使用实际成交价，实时尾点为 9.558，均价由误算的 9.802 修正为约 9.702。隔离浏览器已核对修复前后曲线；未做全量回归或真机测试。

- 休息入口移除目标时长选择，新休息使用自由计时；已在进行的定时休息保留原状态。
- 快速、定时和打卡入口使用 38px 滑动条，约为此前 48px 的 80%，保持既有半透明、小圆角风格。
- 打卡改为滑动确认。验证中、成功、时间条件失败、定位拒绝等反馈直接作用于对应滑动条；成功后禁用重复提交，失败后可重试。周期刷新保留反馈和正在进行的手势，打卡不会触发专注启动。
- 指数数字按相对昨收的日内涨跌着色，最后一笔成交方向只改变渐变背景，数字与背景可呈不同方向。
- 定时专注进度条改用与全天进度条一致的 14px 宽条、4px 小圆角和纯色填充。
- 第二行第二栏将排行榜放在投入统计前，并默认显示排行榜。累计专注、8H目标差值、昨天差值排在同一行；两个差值均按当前学习窗口进度折算，分别显示提前、落后或持平，互不影响颜色。其他七小时统计目标保持既有口径。

日内线问题来自 0.7.2 上线当天的切换时区：启用时刻以 UTC 保存，传给旧曲线生成器时没有转换到账户时区，导致上午旧算法曲线漏读，后续时段起算点也受影响。原始专注记录未丢失。现已统一切换时刻时区，恢复切换前曲线并重算衔接；原启用时刻保留，不重复切换算法。缓存加入引擎修订号以更新受影响的派生数据，成交随机种子和后续日期的计算口径保持不变。

生产库使用只读连接备份到服务器内存核对。当前账户的上午 191 个采样点可从记录重建，冷启动、连续请求与完整/实时接口结果一致。指数计算始终位于服务端 Python；APK 只上报专注状态、读取并展示服务端行情，不计算或上报指数价格。

针对性验证：29 项后端、25 项前端检查，以及 8 项隔离浏览器检查通过；包含 UTC/本地同一切换时刻的等价性、打卡滑动和逐项反馈、横竖屏布局、双差值同排与独立着色。签名 APK 与 lint 检查的最终结果及生产备份、部署核验见 Release 随附 manifest。未做全量回归或真机验证。
