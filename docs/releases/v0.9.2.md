# 0.9.2 · 弹出式专注提醒

- 新提醒默认关闭，在 APP「原子岛与提醒」按需启用。刚开始专注或暂停的五分钟内，以及全屏提醒前一分钟，竖屏右侧、横屏上方显示主题色发光提示。向内滑可打开静默卡。
- 默认连续暂停 12 分钟、结束专注后在开盘时段闲置 20 分钟触发全屏。两类阈值可独立调整或禁用；默认静默选项为 15、30、60 分钟，也可自定义。静默覆盖全部主动提醒，计时和原子岛状态继续更新。休盘期间不催下一段。
- 不透明白底、衬线字体和小圆角；全屏待处理时屏蔽应用内返回，选择回到专注后须实际开始或继续才解除。亮屏解锁且已授予悬浮权限时，退到桌面会尝试重新打开；系统拦截时保留通知入口。Home、锁屏和系统权限设置仍由 Android 管理。
- 关闭提醒需答对一道选择题；答错换题。内置 10 道可离线作答的极限题，支持公式和代码块。可在设置中复制 [题库维护 API 的接入 Prompt](../reminder-question-bank.md)、同步题库或更换专用维护密钥。

原子岛保留自己的提醒节奏、系统计时和主题适配。服务端只新增私有题库及鉴权接口。
