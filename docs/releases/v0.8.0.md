# 0.8.0 正式版

`versionCode=23`，沿用既有签名，可覆盖升级 0.8.0-rc1 与 0.7.6。本版包含 rc1 的统一业务秒拍第一阶段及原子岛系统计时适配，并合并以下改动。

## 模考走势图

同一天、同科目的所有有效成绩聚合为一个日均值点。上下 T 端帽分别表示当天最高、最低值，均值点之间继续连线。保留原有灰度和点形区分、触控缩放校正，以及最近 10 个提交日期的窗口。

纵轴继续按各次提交保存的目标分折算为百分比，范围和均值均在此口径下计算，不把历史成绩改用今天的目标分。详情显示当日均分、范围、提交次数；当日目标分不同时明确显示百分比范围。只有一次成绩或成绩完全相同时，范围退化为均值点。图表纵轴包含最高值，端帽为两端留出空间；保存的原始成绩和顶栏最新成绩口径不变。

## 原子岛保活与提醒

- 系统计时路径每 38 分钟静默刷新一次。该节奏独立于原有十分钟格式更新和定时进度更新，主动提醒展开保护期间顺延；只有成功投递才推进保活时间，不请求重复展开。
- 下一段专注提醒仅在账户配置的开盘时段触发。午间休盘、夜间收盘和早盘前停止此类提醒，跨收盘的稍后提醒也不继续显示下次提醒时间。覆盖真实专注结束和开盘等待两条路径。
- 再次开盘时以新开盘时间重新等待，不补发休盘或隔夜积压的提醒。进程重建时检查并清除已不适用的旧提醒通知。暂停中的“继续专注”提醒、实际专注计时、午间开盘倒计时和打卡倒计时保留原规则。

## rc1 能力与边界

主时间、倒计时、全天时间轴、专注/暂停/休息和累计统计使用共同业务帧及单调经过时间；普通首页响应合并到下一秒，真实状态变化立即显示，并拒绝过期响应。页面隐藏时停止业务计时绘制，恢复时取最新帧。APK 内置授时模块与时间轴，兼容现有生产 HTML。

原子岛系统文字计时限定已验证的 iQOO 15 `V2505A / PD2505B_A_17.1.9.0.W10`，其他固件沿用兼容路径。小胶囊仍为总分钟 `m:ss`，跨十分钟需更新格式，大时间为 `h小时m分钟` 或 `m分钟s秒`。已适配路径展示于通知、锁屏和岛，排除桌面原子通知组件；真实状态、主题、提醒轮次和明显校正立即更新。

主动提醒保持一次展开、15 秒期间不为装饰性更新反复投递、一次到期收起的策略；系统文字可自行走秒，但 ROM 实际展开保持时间和长时间保活效果仍由用户使用正式包真机验收，未将模拟时钟测试视作真机效果保证。

## 验证与交付

50 项前端定向检查、61 项原生相关测试、签名 Release 构建及 lint 通过（0 错误、62 项警告）。浏览器实测覆盖网页与 APK 旧生产 HTML 模式、横竖屏、明暗主题和手机触控，均值点、范围线及详情显示正常。原生测试覆盖两个 38 分钟周期、提醒顺延、午休/夜间/早盘边界、隔夜恢复、跨收盘稍后提醒及账户时区。

本次未做全量回归，未启动模拟器。旧滑动器的两个复用测试在 0.7.6 基线同样失败，仍未纳入本次修复。APK 版本、签名、内置资源及上传附件回下载结果随构建清单核对。

仅发布 APK 和源码，没有部署生产服务端、改写数据库或调整指数计算。500ms 完整数据同步、原生 15 秒对账、WakeLock 及行情逐笔通道保持现有策略；哈希增量同步和更深入的后台省电重构留待后续。
