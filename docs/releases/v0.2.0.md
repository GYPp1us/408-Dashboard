# v0.2.0 · 紧凑控制台与双向后台同步

本版集中修复首个 Android 预览版的迁移体验，并同步压缩网页控制台：

- Android WebView 使用 0.5 初始缩放和原生专属竖屏规则；普通网页始终维持横向两层、下层三列结构；
- 记录站内路由和 WebView 状态，旋转屏幕、进程恢复或重新启动后回到上次页面；已访问页面启用缓存优先加载；
- 前台服务每 15 秒发送心跳并回读服务端状态，网页与通知端的暂停、继续、结束可双向收敛；
- 权限页整体压缩，不再显示无法核验的自启动“待开启”，也不再在每次专注时自动弹出；
- Android 16 实时通知推广设置只在系统确有入口时可点击；其余版本明确标注由系统通知管理；
- 超时提醒优先使用应用悬浮层，无障碍改为不读取窗口内容的可选兜底，最终仍保留高优先级通知；
- 快捷专注固定为四项，支持手动固定与最近使用补位；“其他专注”使用科目—项目双纸带选择；
- 三个主面板等高压缩，活动区在热度、专注走势与模考走势间单项切换；热度格在缩放时维持固定格距比例；
- 专注时移除差值条和冗余标题，重做两级历日榜及纵向时长分布；结束总结移除当日科目构成图。

无 vivo 场景/包名认证时，OriginOS 原子岛形态仍不作保证；普通持续通知、Android Live Update 尝试、后台同步和提醒降级均不依赖 vivo 认证。本版本不包含华为适配。
