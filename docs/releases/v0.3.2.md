# v0.3.2 · 主页可用性修复

本版恢复首次前端重构前的间距、字号、进度条厚度和面板高度，移除横屏强制压缩及快捷数量对整页高度的影响。界面继续使用衬线字体，指数区域使用无衬线字体；上午／下午时间卡片按配置时长分配宽度。窄横屏对导航和时间卡片换行，保持倒计时与操作按钮完整可见。

分时图完整展示账户配置的开盘至收盘时间，按真实时间定位曲线、午休间隔和当前时间。首页移除重复的指数标题及橙色事件点，保留曲线上的实际跳变。首页、长按详情与完整指数页共用时间轴和服务端实时投影，避免分钟合并丢失事件及数据点数量造成的坐标错位。后台或隐藏页面恢复时立即重新获取实时状态，并丢弃已过期的在途响应；Android 通知触发状态同步后，完整指数页也会立即刷新实时曲线。每日 K 线保留日期刻度和悬停日期。

完整指数页新增可选的连胜挑战开关。开启后，从开启时刻起当天指数限幅扩至 ±20%；开启前已经显示的走势保持不变。关闭挑战后，当天仍沿用挑战限幅，次日按账户时区午夜恢复普通 ±10% 限幅。开关状态和变更时刻持久保存，并随版本 3 迁移导出包导出。

主页时钟、日期、时间窗口、学习历史及图表更新时间遵循服务端提供的账户时区。设备设为 GMT/UTC 时，账户为 +08:00 的时钟、窗口进度和交易日期仍显示在同一条账户时间线上。

APP 横屏隐藏系统状态栏与导航栏，取消挖孔及系统栏占位；竖屏恢复安全区。WebView 明确启用 viewport、关闭自动概览与用户页面缩放，以正常比例显示原有字号和间距。网页和 APP 固定文字自动调整策略，主页在返回、恢复可见和切换布局时重新分配列宽。

点击常驻通知返回应用时复用现有主页 Activity 与 WebView，保留当前页面路由，避免重建页面时短暂白屏或丢失路由状态；另为覆盖升级后已保存的通知令牌加入兼容处理。
