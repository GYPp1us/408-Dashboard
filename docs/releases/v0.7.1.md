# v0.7.1 · 三标签专注入口与每日打卡

Android versionName 0.7.1、versionCode 15，沿用既有 release 签名。源码推送 main，创建独立 v0.7.1 标签和正式 Release；0.7.0 保留。

专注入口使用快速专注、定时专注、打卡三个标签。快速和定时各有固定数量栏位，沿用账户的 2～8 项数量设置；不显示星星和点点点。长按栏位可换入、换出；换出后保留空栏位。两类栏位分别持久化在本机、按账户隔离，定时栏位保存事项及分钟参数，例如数学-模拟-180分钟。其他定时专注使用 30m、1h、2h、3h 纸带，时长不再放在主页的独立目标选择器。滑动条、填充和手柄采用小圆角，文字与手柄垂直居中；竖屏仍为原有 60% 缩放和半透明风格。

打卡按账户时区，每日每项一次。在打卡标签维护项目并主动触发，时间段和地点可分别启用，同时启用时都必须满足。时间段支持跨午夜，开始含、结束不含；以服务器接收时间判定，客户端不能传旧时间补过条件。地点用经纬度及 50～10000 米半径，默认 200 米；需要新鲜位置和精度，精度超过半径或距离超过半径时拒绝。只在点击定位或地点打卡时获取位置，不后台定位，不保存轨迹。完成后重复触发/上报返回同一记录，不增加完成数，不影响专注和今日结算。

热度图在两小时时段之外新增一行打卡完成度，与原有日期滑动窗口、键盘选择和长按详情共用日期。没有任务时显示未配置；有任务时为已完成/应完成。规则从创建日开始进入每日目标，移出后停止未来目标，既有完成记录保留；当天已完成但移出的任务仍保留在当天分母中。历史范围也包含早于专注记录的打卡日期。详情显示账户时区的完成时刻。

外部打卡上报使用独立、持久的账户 key；设置提供复制上报链接、复制接入提示和更换 key。协议与专注上报同为 catalog/frame、source/state 快照，打卡状态为 checkin，idle 不改变已经完成的记录。重复帧不会重复打卡，key 只有主动轮换撤销，服务重启和应用 secret 轮换不改变 key；轮换打卡 key 不影响专注 key。API、条件错误和例子见 [打卡协议](../checkin-reporter.md)。

原子岛保持即时状态变化与每秒计时：主动提醒的每次 UPDATE 携带展开请求，关闭提醒后取消该请求，轮次呈现记录仍只持久化一次。进度节点改用带留白及不透明中心的小图标，减少进度轨道穿过图标的视觉重叠。原子模板不再同时叠加 Android Chronometer/ProgressStyle，紧凑卡片计时采用总分钟 m:ss，避免长单位文本变化；真实时间仍每秒更新。桌面闪烁、节点重叠和展开保持的实际改善需由设备所有者用 release APK 验证，不能用字段测试代替 ROM 渲染。

图标来源为目录中 Mutsumi-Atomic-Lab-debug.apk 的 ic_atomic_lab.xml。时钟指针在 48 单位画布上左移 2、下移 2；启动、通知、岛和 APK 页使用同一轮廓。原子图标及进度节点按当前应用主题色着色，缓存随颜色区分；系统主题启动图标由 Android monochrome 处理。

验证：294 项 Python 测试、109 项前端逻辑测试、81 项 JVM 测试通过；签名 release 构建及 lint 零错误。17 组页面回归覆盖三标签、固定栏位、180 分钟纸带、打卡创建/地点/完成、重复外部帧、热度图及上报设置，并保留暂停、提醒关闭、休息、结算、旋转、窄屏主题回归。未启动 Android 模拟器或连接真机。

本版必要服务端变更限于打卡持久化、上报接口、热度图聚合和入口资源。生产激活前使用在线只读快照演练新 schema，并校验所有旧表的行数及内容哈希不变、quick_check 和 foreign_key_check；不更改已有专注、科目、挑战计算或旧上报 key。部署路径、源码提交和演练结果记录于随 release 提供的 manifest。
