# v0.7.6 · 结算状态 hotfix

Android versionName 0.7.6、versionCode 21，沿用既有签名，可覆盖安装在 0.7.5 上。

修复每日结算统计展示 30 秒后，原子岛错误显示“开盘后已等待 xx”并可能再次触发等待提醒的问题。开盘等待逻辑现在始终排除“已结算”状态，覆盖统计展示到期、本机状态恢复及下午开盘。结算后的打卡倒计时继续按原优先级显示。

验证限于原子岛状态选择和提醒持久化的 22 项原生测试，以及签名 Release 构建、lint、版本和下载包校验。未做全量回归、模拟器或真机测试，实际原子岛效果由用户安装 Release APK 验证。

改动只在 APK 端。服务端页面、指数计算、数据库和结算统计口径均沿用 0.7.5，无需更新生产服务。构建提交、签名证书、APK 哈希及检查结果随 Release manifest 提供。
