# 0.9.1 · 前台监测与长暂停修复

## 修复

- 恢复未锁定专注的前台监测：原生服务仅在应用前台时发送前台心跳；退到后台或熄屏不再替用户续期。超过原有 30 秒宽限后结束本段。显式锁定后仍可后台计时，暂停仍保留且不计入有效专注。
- 看板查询不再充当前台心跳，后台原子岛拉取状态不会延长专注。旧版原生后台心跳缺少明确前台标记时不再续期或恢复；超时记录仅允许前台连续短暂断网后的两分钟内恢复，旧会话不能为新会话续期。
- 长暂停运行锁提前续租，避免十分钟到期后失去检查调度。检测到长时间调度中断或返回应用时通知已消失，会恢复原子通知并核对服务端状态，保留暂停起点及已展示提醒的记录。
- 原子通知更新临时失败后继续运行并退避重试，避免一次发布失败让后续计时和同步永久停止。

## 数据修正

对已确认的异常长时专注做单条指纹校验、服务器本地备份和定点剔除；重新计算受影响日期之后的指数缓存。核对其他专注、历史指数、设置、每日计划和结算记录保持一致。维护脚本不导出业务内容，遇到任务归类或冻结结算会停止。

## 验证范围

46 项后端、29 项前端、62 项原生定向测试及 Release lint 通过。覆盖前后台心跳、锁定和暂停豁免、短断网恢复与长时间离开、旧客户端心跳、旧会话串扰、跨午休五小时暂停及八小时运行锁续租。使用正式签名构建，保留系统自主走秒、38 分钟静默续期和每轮提醒只主动展开一次的原有策略。

未做全量回归。目标 vivo 固件上的长时间后台实际渲染仍由 Release APK 真机验证。
