# v0.7.2 · 逐点成交、温和价值回拉与模考走势图修复

Android versionName 0.7.2、versionCode 16，沿用既有 release 签名，可覆盖升级。保留 0.7.1 的完整打卡系统：三标签专注入口、时间段/地点条件、每日热度完成度，以及设置中的独立外部打卡上报与 key 轮换。旧 Release 保留。

专注指数盘中每笔真实合成成交只移动 0.001，两笔至少间隔 100 毫秒。分钟点、高低值和实时行情由同一本盘口生成，前端按服务器成交记录播放，不再按斜率虚构中间价格。行情每秒同步，数字和低饱和度渐变背景依最后成交方向着色，移除报价闪烁动画。

开始、结束和暂停等切换的额外压力减小，默认分 8 分钟释放，可设置为 5～10 分钟；反向未释放压力相互抵消，避免反复开关叠加。普通扰动保持 0.009，报价跟随时间为 45 秒。

支撑、压力距离作为反向动量的启用距离，默认昨收的 1.2%。移除目标价压缩及越界拦单，允许越过价值区间后继续向外成交；偏离越远，反向压力在三个连续层级逐渐增强，以 120 秒响应积累，回到区间后逐渐消散。每日涨跌停、开盘/重开/收盘竞价和既有价值口径保留。新算法只从部署时刻启用，旧日期及该时刻前的分钟点保持既有计算。

模考走势图修复竖屏与横屏缩放后的触控定位，使同一科目在其他科目日期穿插时仍正常连线。科目使用稳定的灰度和不同点形区分，悬停及深色主题保留点形；提示框不再拦截触控。

本次只运行相关模型、打卡和前端逻辑检查，并构建签名 Release APK；不做全量回归。此前的隔离浏览器检查覆盖模考图触控/连线和实际成交界面。真机验证由设备所有者下载 Release APK 完成。

发布包含 main 源码、独立 v0.7.2 标签、生产部署、APK、SHA-256 和产物 manifest。生产更新前保存一致性数据库备份，并在副本演练初始化，确认除新增指数设置及全局切换时刻外，既有数据与打卡记录保持不变；保留旧目录以便回滚。最终提交、签名、检查数量和部署证据见 Release 随附 manifest。
