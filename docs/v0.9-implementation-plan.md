# 0.9.0 实施与验收范围

2026-10-24，基于 0.8.0。先完成实现、定向验证和各个新 UI 的实际预览截图，再交由用户查看；本阶段不直接发布或部署生产。

## 已确认

- 新增每日计划与完成记录，可把一段已结束的专注归类到一个任务；同一任务可关联多段专注。
- Agent 接入以本端协议为准。计划上报、读取今日待办状态采用独立、长期有效、可轮换的鉴权 key，提供链接及完整 Prompt 复制。
- 每日结算冻结任务完成快照，并异步主动推送到用户配置的 HTTPS 地址，支持可选鉴权密钥。失败不阻塞结算，持久保存重试；幂等事件 ID 不变。
- 原子岛显示同步中、同步成功、失败待重试或未配置；保持实际专注、暂停和休息优先级，不重复主动展开。
- 每日结算的历史报告和推送快照保持不可变。取消结算时停止未发送任务，并对已发送/可能已发送的事件推送撤销记录。
- 保留鉴权的今日待办实时读取接口，供 Agent 主动查询结算后的最新状态。
- 恢复 APP 竖屏“本段专注结算与休息计时”全屏页：本段数据、休息走秒、任务归类与是否完成。
- APP 竖屏每日结算改为复合布局的全屏页，包含任务、打卡及原有统计，尽量一屏呈现，保留长列表滚动的容错。
- 竖屏主页整体视觉比例约为当前 1.15 倍、增加两侧留白；隐藏进度面板左侧的重复当前时间，将时钟放入应用状态栏。
- 修正 Android 系统状态栏背后的异常深色背景，跟随主题，并保留横屏沉浸模式。
- 排查上级纸带改变后下级无法拖动的问题；覆盖程序居中、滚动回调、指针捕获和不同 UI 缩放。
- 保留现有横屏布局，使用 0.8.0 截图作对照；新增业务所需的后端代码与 APP 资产一起准备，不为旧网页做额外响应式重构。

## 协议与数据原则

- 计划以账户、计划日期、来源、外部任务标识归属。最少提供任务名称；没有外部 ID 时以规范化名称生成稳定 ID。重复上报幂等、不会因为省略完成状态而重置已完成记录。
- 默认日期按账户时区的服务端当前日计算；时间以服务端记录为准。
- 关联只接受本账户已结束的专注，完成时间使用已有专注数据扣除暂停；重复保存不会重复计时。
- 完成变更单独记事件，读取返回完成状态、累计专注秒数、关联记录及修订版本。
- 推送使用不可变结算事件、至少一次投递及接收方按事件 ID 去重。验证公网 HTTPS 目标，不自动跟随重定向；不在页面或日志回显已有密钥。
- 未配置推送地址时仍保存结算和任务记录，不伪报成功。

## 预览与检查

需要提供竖屏主页、本段结算/休息、每日任务、每日结算、接入与推送设置的预览，至少包含浅色和深色主题样例；并核对横屏原有布局。截图来自实际实现和隔离测试数据，明确与 Android 真机系统栏效果区分。

检查包括账户隔离、鉴权轮换、上报幂等、归类计时与完成更正、结算快照/重试/取消、同步状态优先级、纸带上级切换后下级首末项可达、手机横竖切换和进度标签边界。所有测试只使用隔离数据库；不改生产专注或指数数据。

## 本轮完成记录

- 已实现上述每日计划接口、完成事件、专注归类、结算快照、持久化推送、补偿撤销及 APP 页面；协议见 `daily-plan-agent-protocol.md`，APP 可复制实际账户 Prompt。
- 默认账户私有：访客的既有公开结算统计继续可读，但不返回任务名称、备注、完成历史及接入信息。
- 推送 worker 支持多进程 SQLite 租约；租约过期后的迟到结果不能覆盖新 worker 的状态。成功以接收方 2xx 为准，重试复用同一不可变事件。测试中未调用真实接收端。
- 岛同步提示只在已结算状态显示，不抢占专注、暂停或休息；等待中短期加快拉取，成功/失败提示到期后恢复常规节奏，不重复主动展开。待推送最多展示 10 分钟，成功 15 秒，失败或待配置 30 秒；设置页保留持久状态及重试入口。
- 已结束专注可以保存归类，或“保存并继续”进入下一段；保存期间冻结输入，冲突先重新读取，不覆盖其他端新状态。
- 竖屏比例由 0.60 改为 0.69；系统栏根视图背景跟随主题，复用现有授时帧更新顶部时钟和休息时长。新增全屏页抵消主页缩放，避免宽度二次放大；旧横屏结算仍使用原模板。
- 纸带修复包括缩放下的坐标换算、取消上一次重建回调、程序居中与用户滚动分离、触摸交由原生滚动处理；浏览器实际交互验证了连续切换上级后子项目首末项仍可达。
- 后端：原有相关套件 89 项 + 新任务/推送 17 项，共 106 项定向用例通过（整合 105 项通过后，新增租约迟到场景并重跑任务 17 项）。前端定向 59 项通过；Android 相关 25 项通过。没有执行全量回归。
- 真实页面验证：412×892、393×792、360×740，无横向溢出；常规 5 项计划的日结页在 393×792 可一屏呈现，更多任务及更矮屏幕可滚动。验证了任务保存、休息走秒、Prompt 复制、请求失败后重试、保存并继续、横竖切换和原生返回键。
