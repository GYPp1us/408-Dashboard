# 0.7 真机验证清单

由设备所有者从 GitHub Release 下载 `Mutsumi-Focus-v0.7.0.apk`，覆盖安装。此清单是待验收项目，不是已完成的真机测试记录。版本名 `0.7.0`，版本码 `13`。

## 基础与原子岛

1. 覆盖安装后账户、事项及已有场景授权保留；竖屏顶部没有独立设置条。原网页设置页内可打开“原子岛与提醒”。通知、原子岛、后台计时状态文字与按钮可读；强提醒默认关闭。
2. 自由计时启动一段，检查岛上事项简写、有效时长；点击岛展开卡片，核对完整事项、暂停、结束和详情。再选择 25 分钟目标启动，核对进度。查看详情不能改变计时状态。
3. 暂停后有效专注时长不增长；暂停时长单独增长，卡片和通知显示下一次提醒。分别从岛、通知与应用继续/暂停/结束，其余位置同步更新。快速重复点击只完成一次操作。
4. 正常结束后，岛显示事项与有效时长，约 30 秒后收起。查看总结可返回本次总结；“选择下一段”打开事项选择，不自动启动旧事项。

## 提醒与休息

5. 暂停满 5 分钟：前台在专注卡片内提醒；后台通过岛和通知提醒，不强制覆盖当前应用。只有首次到达阶段时提示，日常计时更新不反复响铃或震动。
6. 查看提醒后仍暂停，本次提醒收起；划掉提醒通知后不会立即重新弹出。再等 5 分钟后，岛、通知和应用的下一次提醒一致，旧提示收起，在新的时间再提示。继续专注必须实际恢复计时。
7. 正常结束后检查 15、30、60 分钟阶段提示。已处理阶段不重发；很晚恢复时只提示最新到达阶段。再等 5 分钟使用统一的新时间。最后一阶段收起后停止离开提醒。
8. 主动休息选择自由计时及 15 分钟目标：显示休息累计或剩余时间；退后台、锁屏、关闭后重新打开，起点不重置。目标到达后剩余保持零，不自动恢复专注。休息期间不产生暂停或离开催促。从岛结束休息，页面和通知一起退出休息。
9. 今日结算后收起已有提醒，停止后续离开催促。从其他设备继续、暂停、结束或结算后，手机在下一次成功同步时显示相同专注状态。休息与延后是 APK 本地状态，不跨设备同步。
10. 主动开启强提醒后再测试超时：圆角半透明覆盖层可继续、延后或查看。未给悬浮层权限时正常退化为通知；关闭强提醒后已有覆盖层立即消失。

## 页面与恢复

11. 竖屏第一屏直接操作当前专注；今日投入在下方，图表与附加操作可展开；浏览长内容时底部计时/暂停/继续可用。休息期间仍可浏览统计及详情。
12. 输入设置草稿、展开详情并滚动，旋转横竖屏；页面、草稿、计时与展开状态保持，键盘不遮住当前输入和主要按钮。横屏首页比例仍均衡；深浅模式与陶土、鼠尾草、海蓝配色可读。
13. 断网后从岛执行操作：显示处理中及未确认/重试，不假装成功。恢复网络后先回读实际状态；若此前请求已完成，不重复结束或错误恢复。退出登录清理本账号运行状态。
14. 通知被系统降级、原子岛关闭或授权不可用时，普通通知仍包含对应状态与操作。已有授权无需反复配对；重新配对、启用与撤销引导字体、步骤、结果和返回入口可用。

记录问题时提供 APK 版本、手机型号/系统版本、操作入口、操作前状态与实际结果；岛渲染问题附相应截图。原子岛卡片、原生 PendingIntent、后台保活和输入法行为目前均待真机验证。
